# Are U Serious

A single-page joke site: tap "No" and it shrinks and dodges away, tap "Yes" and it fills the screen and reveals the reaction image.

## Deploy to Vercel

1. Install the Vercel CLI if you don't have it:
   ```
   npm i -g vercel
   ```
2. From inside this folder, run:
   ```
   vercel
   ```
3. Follow the prompts (log in, confirm project settings — defaults are fine since this is a static site).
4. For production deploy:
   ```
   vercel --prod
   ```

Alternatively, drag-and-drop this folder onto https://vercel.com/new, or push it to a GitHub repo and import it in the Vercel dashboard.
